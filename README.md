# Сатурн — прототип 99, Тип 3

**За каждые полные 1000 ₽ товаров акции — один подарок на выбор из трёх. Кратно, без ограничения количества порогов.**

Публичный адрес: https://kate854.github.io/99/ . Исходники — ветка `main`, сайт — `gh-pages`.

## Запуск и скачивание

```sh
npm install
npm run dev
```

- `npm test` — 33 теста бизнес-логики и выбора подарков.
- `npm run build` — проверка TypeScript и сборка одного автономного HTML.
- `npm run preview` — просмотр production-сборки.
- `app/index.html` — точка входа исходного приложения для Vite; корневой `index.html` — автономная публикация.
- `prototype.html` — готовый HTML для скачивания и открытия браузером без сервера. React, SVG, CSS и логика встроены.
- `docs/index.html` — идентичная копия для публикации. После сборки скопируйте `dist/index.html` в корневой `index.html`, `prototype.html` и `docs/index.html`, затем обновите файл `index.html` ветки `gh-pages`.

## Сценарий макетов

1. Начальные товары акции: 555 ₽; до первого подарка 445 ₽.
2. В «Добавить товары» 444 ₽ дают всего 999 ₽: подтверждение недоступно. Товар за 700 ₽ даёт 1255 ₽: выбор товаров можно подтвердить.
3. В корзине появляется кнопка «Выбрать подарок». Подарок автоматически не выбирается. Шапка остаётся нейтральной: до второго подарка 745 ₽.
4. В поп-апе «Выберите подарок» доступны три варианта, но квота — только **один** подарок. После выбора одного другие варианты бледные и недоступны. Выбор — черновик до подтверждения.
5. Подтверждение добавляет бесплатную подарочную строку. Кнопка шапки становится «Изменить подарок».
6. Увеличить количество клея за 700 ₽ до трёх: 2655 ₽ → квота **два** подарка, до третьего 345 ₽. Первый выбранный подарок остаётся.
7. Открыть выбор: «Доступно: 2 подарка», первый уже добавлен, подтверждение недоступно до второго выбора.
8. Выбрать второй подарок и подтвердить. В корзине две подарочные строки, кнопка «Изменить подарки».

## Подарки

- Лента армирующая Knauf Курт 50 мм x 25 м — вариант комплектации «4 рул.».
- Лента уплотнительная Knauf Дихтунгсбанд, 0,03x30 м — «2 рул.».
- Штукатурка Церезит CT 64 короед 2,0 мм база, 25 кг — «1 шт.».

Каждый выбранный вариант занимает **одно место** подарочной квоты. Подписи «4 рул.» и «2 рул.» перенесены из макета как описание варианта; в корзине количество 1 означает один выбранный подарок/комплект, как в приложенных состояниях.

Количество мест = `floor(сумма товаров акции / 1000)`. Неакционные позиции, услуги и подарки не учитываются. На границах 1000 / 2000 ₽ доступны 1 / 2 места, а сумма до следующего подарка — 1000 ₽. Вычисления в копейках.

Подарки можно повторять: кнопка «+» у выбранного варианта добавляет ещё такой же подарок, пока есть свободные места. Поэтому при четырёх и более порогах каталог из трёх видов не становится ограничением. Повторы группируются в одну бесплатную строку с количеством. Чтобы изменить вариант, нажмите «Добавлено», затем выберите другой. Подтверждение доступно, когда заполнены все заработанные места и есть изменения.

При снижении суммы подарки сверх квоты автоматически убираются, сохраняя первые выбранные. При новом пороге появляется дополнительное свободное место, существующий выбор сохраняется.

## Удаление точно как в прототипе №8

Корзина справа удаляет подарочную строку целиком. Ни изображения, ни названия, ни карточки удалённого подарка в списке не остаётся. Под подарочным списком появляется тот же блок `.gift-restore`, что в №8: **«Удалено: N подарков»** и **«Вернуть подарки»**. Шапка не меняется и продолжает показывать следующий порог и обычные кнопки.

Возврат сразу восстанавливает именно удалённые варианты и их количества, без открытия поп-апа. Другие выбранные подарки и сумма заказа не меняются. Количество восстановленных подарков ограничено текущей квотой. Если квота уменьшилась, память удалённых подарков ограничивается свободными местами; подтверждение нового полного выбора очищает её.

## Проверено

33 теста: точные границы сумм, квоты, копейки, три уникальных варианта, блокировка лишнего выбора при одном месте, сохранение первого выбора при двух, отмена, замена, удаление, повторные варианты, снижение квоты, отсутствие дублей и мутаций.

В Chromium кликами пройдены все 11 состояний макетов, включая суммы 1255/2655 ₽, выбор одного/двух подарков, блок удаления под подарочным списком, как в №8, восстановление и замену, четыре способа закрытия, клавиатурный фокус, мобильный экран, повтор одного варианта четыре раза и автономность HTML. Ошибок JavaScript не обнаружено.

## Дизайн и демонстрационные данные

Реальные компоненты React + TypeScript + Vite. Макеты целиком как фон не используются. Изображения упаковок, лент и знак логотипа — локальные SVG-иллюстрации; оригинальные фотографии отдельно не предоставлены.

Как в предыдущих прототипах, итоги рассчитываются по ценам строк: показанный на макетах итог 10 725 ₽ не совпадает с их суммой. Четвёртый неакционный товар Granit Fix за 967 ₽ взят из финального макета. Услуги, скидка по карте и бонусы вне подарочной механики остаются демонстрационными данными. Backend отсутствует.
